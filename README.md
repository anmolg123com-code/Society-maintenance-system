# Civiora - Society Maintenance Management System

A comprehensive dashboard for managing society maintenance operations, including tracking maintenance requests, scheduling tasks, managing residents, and handling bills and payments. Built with the Civiora platform.

## Features

- **Dashboard Overview**: Real-time statistics and analytics
- **Maintenance Tracking**: Monitor pending and completed maintenance requests
- **Task Scheduling**: Schedule and track maintenance activities
- **Resident Management**: Manage resident information and profiles
- **Billing System**: Handle bills and payments
- **Reporting**: Generate reports and analytics
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Secure Authentication**: Login system with validation

## Components

- **Login Page**: Secure authentication with form validation
- **Navigation Sidebar**: Easy access to all system modules
- **Statistics Cards**: Key metrics at a glance
- **Data Visualization**: Charts and graphs for maintenance trends
- **Activity Feed**: Recent system activities
- **Quick Actions**: One-click access to common tasks

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js for data visualization
- Font Awesome for icons

## Installation

1. Clone or download the project files
2. Open `index.html` in your preferred web browser to access the Civiora dashboard
3. Open `login.html` in your preferred web browser to access the Civiora login page
4. The system is ready to use

## Usage

The dashboard provides an intuitive interface for managing society maintenance operations:

- Use the sidebar to navigate between different modules
- View key statistics in the dashboard cards
- Check recent activities in the activity feed
- Use quick action buttons for common tasks
- View maintenance trends in the charts

The login page provides secure access:

- Enter your credentials to log in
- Use social login options
- Reset password if needed

## Customization

The system can be easily customized to fit specific society requirements:

- Modify CSS variables in `style.css` for Civiora branding
- Update chart data in `dashboard.js` for different metrics
- Add new modules to the sidebar navigation
- Customize login background by replacing the background image
